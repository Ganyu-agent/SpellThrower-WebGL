# Spell Thrower

Spell Thrower는 8×8 전장에서 두 명이 주문 카드를 사용해 싸우는 턴제 전술 카드 게임입니다. 카드를 언제 사용할지뿐 아니라 상대를 어디로 밀어낼지, 장판과 구조물을 어디에 배치할지까지 고려해야 합니다.

## 플레이 링크

[온라인으로 플레이하기 => (https://ganyu-agent.github.io/SpellThrower-WebGL/)](https://ganyu-agent.github.io/SpellThrower-WebGL/)

설치와 별도 게임 계정 로그인이 필요하지 않습니다. 같은 기기의 브라우저 탭 두 개 또는 서로 다른 두 기기에서 각각 접속해 대전할 수 있습니다.
두 기기는 같은 LAN 에 속해있으면 됩니다.

즉 특수한 경우가 아니라면, 두 기기가 같은 WiFi 에 연결되어 있으면 문제 없이 매칭이 됩니다.

## 게임 플레이 방법
> **원활한 게임진행을 위해 플레이 방법은 읽으시는걸 추천드립니다.**
>
> 카드 효과는 가볍게 훑으시면 좋으나, 소울식 학습법을 원하시는 분들이라면 카드는 설명을 읽지 않으셔도 됩니다.


### 기본 셋팅

- 두 플레이어는 각각 HP 50으로 시작합니다.
- 상대 HP를 0으로 만들면 즉시 승리합니다.
- 최대 25라운드까지 진행하며, 그때까지 양쪽이 살아 있으면 HP가 높은 플레이어가 승리합니다. HP가 같으면 후공(P2)이 승리합니다.

### 게임 시작

1. 플레이 링크에서 **START**를 누르고 닉네임을 등록합니다.
2. **DECK**에서 25장 덱을 확인하거나 구성합니다.
3. 로비로 돌아와 두 플레이어 모두 **MATCH**를 누릅니다.
4. 상대가 연결되고 두 덱이 제출되면 게임이 자동으로 시작됩니다.

덱은 25장이어야 하며, 일반 카드는 같은 종류를 최대 2장까지 넣을 수 있습니다. **듀얼을 신청하지** 카드는 최대 1장만 넣을 수 있고, 덱에는 최소 13종의 카드가 필요합니다. **이동** 카드는 덱에 넣지 않으며 매 턴 조건에 따라 자동으로 지급됩니다.

**MATCH**는 카드 13장 이상을 선택하기 전에는 대기열에 들어가지 않고 현재 선택 수를 안내합니다. 실제 대전 제출 시에는 위의 25장 덱 규칙도 함께 확인합니다.

### 턴 진행

1. 자기 턴에 손패에서 카드를 드래그해 보드의 유효한 칸에 놓습니다. 카드 위에 마우스를 올리거나 클릭하면 카드 상세 정보를 확인할 수 있습니다.
2. 카드는 코스트를 소모합니다. 첫 턴 코스트는 4이며 라운드마다 1씩 늘어나 최대 10까지 충전됩니다. 코스트가 부족하거나 유효하지 않은 칸에는 카드를 사용할 수 없습니다.
3. 공격·회복·이동·장판·구조물 카드를 원하는 순서로 사용한 뒤 **END TURN**을 누릅니다.
4. 턴 종료 시 효과의 소유자와 발동 조건에 맞는 장판·구조물이 발동하고, 지속 효과가 정리됩니다. 이후 상대 턴이 시작되며 드로우·회복·이동 카드 지급이 적용됩니다.

자기 턴에는 45초의 제한 시간이 있습니다. 시간이 끝나면 자동으로 턴이 넘어갑니다. 기본 이동은 코스트 0의 **이동** 카드로 표시되며 한 번 사용할 수 있습니다. 사용하지 않은 이동 카드는 턴 종료 시 사라집니다. 얼음의 이동 봉쇄 효과를 받으면 해당 턴의 이동 카드도 지급되지 않습니다.

### 보드와 타깃팅

- 보드는 8×8 칸으로 구성되며 맵 장애물과 플레이어가 이동을 막습니다.
- 카드에서 손을 떼면 카드가 허용하는 칸만 강조됩니다. 카드 종류에 따라 적, 빈 칸, 방향 또는 자기 자신을 지정합니다.
- 대부분의 공격은 사거리와 시야를 확인하며, 장애물에 가로막힙니다. 장애물을 무시하는 번개 계열과 빈 칸을 지정하는 장판·구조물 카드는 별도 규칙을 사용합니다.
- 이동 카드는 가로·세로·대각선으로 이동합니다. 얼음 장판이나 이동 관련 효과가 이동 거리에 영향을 줍니다.
- 장판과 구조물은 보드에 남아 위치와 남은 턴 또는 HP가 표시됩니다. 구조물은 칸을 차지하므로 이동과 다른 구조물 배치를 막습니다.

## 카드 효과

카드의 수치는 현재 공개 빌드의 실제 규칙을 기준으로 표시했습니다. `사거리`는 시전자와 타깃 칸 사이의 맨해튼 거리이며, `비용`은 해당 카드를 사용하는 데 필요한 코스트입니다.
그러므로 대각선방향은 거리 1도 1.5도 아니고 2로 계산해야 합니다.
